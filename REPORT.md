## 1. Пояснення до коду

*Модуль celsius_fahrenheit.py містить дві функції:*

*celsius_to_fahrenheit(c) - переводить температуру з Цельсія у Фаренгейт за формулою F = C * 9 / 5 + 32;*
*fahrenheit_to_celsius(f) - переводить температуру з Фаренгейта у Цельсій за формулою C = (F - 32) * 5 / 9.*

*Модуль celsius_kelvin.py містить дві функції:*

*celsius_to_kelvin(c) — переводить температуру з Цельсія у Кельвін за формулою K = C + 273.15;*
*kelvin_to_celsius(k) — переводить температуру з Кельвіна у Цельсій за формулою C = K - 273.15.*

*Програма lab6.py:*

*імпортує функції з обох модулів пакета (from src.celsius_fahrenheit import ..., from src.celsius_kelvin import ...);*
*використовує модуль math зі стандартної бібліотеки (функція math.ceil для округлення результату вгору);*
*використовує сторонній пакет requests, встановлений через pip, для виконання GET-запиту до Google та виведення статус коду відповіді. Виняткова ситуація requests.exceptions.RequestException обробляється в блоці try/except;*
*викликає функції конвертації з різними аргументами та виводить результати.*

*Тести tests/test_lab6.py написано за допомогою модуля unittest. Для кожної з чотирьох функцій створено окремий тест з трьома наборами значень. Для порівняння дробових чисел використано assertAlmostEqual.*

*Запуск:*

*pip install -r requirements.txt*
*python -m unittest discover -s tests -t .*
*python -m src.lab6*

## 2. Контрольне запитання

**Запитання:** `Що таке файл __init__.py і яка його роль у пакетах?`

**Відповідь:**

`__init__.py - це спеціальний файл, який розміщується в директорії та позначає її як пакет. Він автоматично виконується під час першого імпорту пакета або його модулів.`

`Ролі файлу __init__.py:`

`Позначає директорію як пакет. Завдяки йому з директорії можна імпортувати модулі: from src.celsius_kelvin import celsius_to_kelvin.`
`Ініціалізація пакета. Код у __init__.py виконується під час імпорту, тому там можна налаштувати стан пакета, змінні тощо.`
`Спрощення імпорту. Якщо в __init__.py написати from .celsius_kelvin import celsius_to_kelvin, то функцію можна буде імпортувати прямо з пакета: from src import celsius_to_kelvin.`
`Керування import *. За допомогою списку __all__ можна задати, які імена імпортуються конструкцією from пакет import *.`
